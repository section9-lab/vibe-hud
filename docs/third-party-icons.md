# Agent icons

WorkBuddy's color icon and monochrome mark come from [LobeHub Icons](https://lobehub.com/icons/workbuddy), in the [lobehub/lobe-icons](https://github.com/lobehub/lobe-icons) repository:

- `packages/static-svg/icons/workbuddy-color.svg` → `AgentWorkBuddy.imageset/workbuddy.svg`
- `packages/static-svg/icons/workbuddy.svg` → `AgentWorkBuddyMono.imageset/workbuddy.svg`

The paths and brand colors are unchanged. Web-only sizing/style attributes were removed; the monochrome mark uses explicit white instead of CSS `currentColor` for native asset rendering.

LobeHub's MIT license is included in `VibeHUD/Resources/LobeIcons-LICENSE.txt`.
