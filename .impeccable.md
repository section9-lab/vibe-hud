## Design Context

### Users
macOS developers who run several coding-agent sessions at once and use the notch as an ambient control surface. They need to understand active agent types, total running-session count, and attention states without opening the HUD or leaving their terminal workflow.

### Brand Personality
Native, compact, and precise. The interface should feel calm while idle and visibly alive only when work is actually progressing.

### Aesthetic Direction
Use a restrained, dark macOS-native visual language that fits the physical display notch. Compact status summaries may borrow the concentric information hierarchy of Apple Health activity rings while remaining visually consistent with vibe hud's existing pixel and terminal-inspired details. Agent identity uses the product color mapping defined by the project owner: Claude orange; Codex and GitHub Copilot white; Pi, OpenCode, and Cursor gray; WorkBuddy green.

### Design Principles
- Make multi-agent state readable at a glance in the closed notch.
- Use motion only to communicate active processing; idle sources remain still.
- Preserve information hierarchy in very little space: source rings outside, total running-session count at the center.
- Keep the HUD dark, high-contrast, and visually native to macOS.
- Respect reduced-motion preferences and never rely on animation alone to convey state.
